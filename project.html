Atlas 7 development roadmap

3D map research

An experimental WebGL perspective module exists. Reliable 3D for GTA V, Online and both Leonida reconstructions requires licensed elevation data, calibration and separate browser validation; it is not yet a completed feature.

Better navigation

Refine nested legends, discovery filters, accessible controls, precise coordinate search and marker completeness without inventing locations.

Safer deployment

Separate GitHub development branch, tests and Cloudflare preview deployments. No production merge before approval. Private research belongs behind actual access controls, never merely a hidden public page.

Technical foundation

Frontend

Responsive HTML, CSS and JavaScript; 2D map controls and optional experimental perspective/WebGL components.

Data and integrity

JSON records, game-specific filters, evidence labels, coordinate transforms and manual licensing review for third-party assets.

Progress and collaboration

Device-local progress, exportable backups, GitHub history, branch review and repeatable static validation.

What this preview does not claim

Atlas 7.0 Preview is the current presentation and development baseline, not proof that every proposed 7.0 feature has shipped. This preview is built from our previously supplied working foundation; the separately completed intermediate source package still needs code-level verification. Live deployment, real 3D terrain, full GTAWeb/GTADB parity, verified GTA VI coordinates and unrestricted image rights are not certified.

See credits and licensing, historical comparison, calibration and verification.

What's next

Test this development preview on Cloudflare after connecting GitHub, review live tiles and browser behavior, reconcile the separately completed development build, and advance the shared 3D engine without altering production main.
