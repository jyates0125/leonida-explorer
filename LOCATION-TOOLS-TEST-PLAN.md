# Atlas 5.7 Location Edition — Manual live test plan

Run after uploading site files.

1. Open GTA V. Search for a named place; check map artwork and map pin.
2. Type Sandy Shores in Area/neighborhood. Confirm the Find list changes. Clear it.
3. Select a pin; open Nearby locations, select 500. Confirm sorted distances.
4. Choose Route nearest 12; confirm route lines and no more than twelve new stops.
5. Enter X=0, Y=0; Go to X,Y and Copy exact map location link; open link in a private window.
6. Open GTA Online. Check that Story-only collectible locations are absent and progress is independent.
7. Switch to GTA VI; check the provisional label and exact coordinate crosshair.
8. Enable one world-object feed and verify its pins are NOT added to the collectible total.
9. Check page on iPhone: pinch zoom, pan, Nearby list, and scrolling.
10. Run Atlas Test Center local checks, then optional live feed checks.

Passing static tests does not guarantee remote feeds, artwork, or real gameplay spawns.
