# Atlas 6.1 — Scaly / Loki Final Original-View Update

### Delivered
- Six VI views: Scaly (YANIS V17 with original color treatment), Loki (DUPZOR V51 with original color treatment), original YANIS 17/15, original DUPZOR 51 and CYBER legacy (with disclosed fallback).
- Removed combined-overlap and UV options in VI. GTA V/Online maps untouched.
- Individual drop-shaped pins use CC BY GTADB source colors where present; legend categories with original Unicode emoji markers.
- In-app WebGL 3D with an additional no-texture visibility fallback; native elevation **not bundled**. 3D may display a flat terrain plane until licensed heightfield provided. No GTA buildings or invented 3D relief.
- Named, multiple route stops, visible straight-line disclaimer unless a separately licensed road graph imported.
- Daily optional GitHub Actions VI snapshot sync from GTADB repository; source licenses and version manifest, validation tests.
- Existing V/Online records and saved collectible progress retained.

### Limitations
- This is not a copy of GTADB's full application or proprietary service API. Exact GTADB UI/code not copied; license-based adaptation and original UI.
- Pixel-perfect photo-basemap / authoritative GTA VI 3D road model not available. Scaly and Loki use different **licensed illustrated maps**; the selected location can show corresponding GTADB and real-world reference photos where supplied.
- No auto-sync starts until the user enables the included workflow. The browser uses the GTADB GitHub raw fallback; some networks may block external downloads.
- GTADB community coordinates are provisional/unverified; real-world addresses are references, not in-game addresses.
- Verify actual GitHub Pages after manual upload and test in browsers; packaging tests do not equal live deployment.
