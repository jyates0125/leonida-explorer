Team Jura Atlas is an independently built interactive Grand Theft Auto map companion. We combine openly licensed landmark data with original map controls, search, smart category suggestions, saved progress, waypoint planning, and a vehicle garage tracker.

Engineering behind the project

Frontend

Vanilla JavaScript, HTML5 canvas, CSS, pointer gestures, keyboard zoom, locally rendered map markers and a responsive mobile/desktop design.

Data + algorithms

Normalized JSON landmarks, evidence-based heuristics, categorized markers, map coordinate transforms, point clustering and nearest-neighbor waypoint ordering (not road routing).

State + offline

Browser local storage for ownership, favorites and pins; JSON export/import; a service worker and Cache Storage for shell files and previously accessed datasets and tiles.

Verification and student presentation

Atlas 5.7 adds tested coordinate adapters for Story Mode and provisional Leonida locations, independently checked game-world reference points, and simulated-browser UI checks for source overlays, coordinate jump and game-mode separation. Live network map tiles, third-party JSON feeds, and the deployed GitHub Pages release still require user-device verification.

Community, open source, and what's next

We welcome bug reports, feature suggestions, and sourced location corrections through GitHub Issues. GTADB supplies CC BY 4.0 landmark data and map tiles; GTAWeb.eu's public issues and feature descriptions inspire UX benchmarking, not copied map datasets. Team Jura's original code is offered under a separate permissive license.
