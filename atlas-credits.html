🍁❄️ Team Jura Atlas 5.0 — Credits & reuse policy

Team Jura is an unofficial, noncommercial fan map project. It is not affiliated with Rockstar Games, Take-Two Interactive, GTADB, or GTAWeb.

GTADB.org map data and imagery

Atlas 5.0 uses the GTA V and GTA VI landmark datasets and may load game-specific image tiles from GTADB.org's public GitHub repository. Data and image tiles in that repository are designated Creative Commons Attribution 4.0 International (CC BY 4.0), except where separately noted. Attribution: GTADB.ORG and contributors.

Changes made by Team Jura: reorganized tags into map categories, added search and visibility controls, custom pin styling, clustering, route waypoints, progress tracking, browser caching and offline overview controls. GTA VI landmarks and map positions are community reconstructions and may be incorrect or incomplete.

For repository sources, see GTA V landmarks, GTA VI landmarks, map tiles, and the data license.

GTADB's project README asks other developers not to repeatedly fetch media or data from its live production server. Accordingly, this Atlas downloads tiles and full landmark updates from the GitHub repository and caches successful downloads in the visitor's browser.

MIT software license for GTADB reference implementation

The implementation references the documented GTADB map-space and tile-index scheme found in its MIT-licensed map code. Sources for collectibles, vehicle spawns and toolkit data

GTADB’s landmark datasets are not a complete GTA Online collectible or vehicle spawn database. Atlas 5.0 does not pretend otherwise. The new Collections and Vehicles panels display imported licensed point datasets or manually saved locations, not fabricated pins. An optional schema permits users to add documented lawful data packs. The separate Toolkit includes manually maintained checklists and business settings; these do not read or update in-game Rockstar account information.

GTA V Story, GTA Online, and GTA VI each have their own page. GTA Online shares GTA V terrain and landmark references, but its own collectible and spawn packs, progress records and route lists are separate.

Other map sources and rights

GTAWeb.eu is used only as a feature and usability benchmark. No GTAWeb website code, collected coordinates, tiles, icons, or images are copied into Atlas 5.0.

Grand Theft Auto, Los Santos, Leonida and all underlying game-world intellectual property and original game artwork belong to Rockstar Games / Take-Two Interactive and their respective rights holders. A community project's CC BY license does not necessarily grant broader rights to original game materials. The project is unofficial and rights holders may request corrections or removal.

Offline limitations

The site-owned interface and starter records are cached for offline revisit after this page's service worker installs. When first fetched successfully, the full GTA V and VI landmark datasets are stored in the browser. The Save overview button attempts to store the selected game and layer's zoom 0–2 tiles; zoom 3–5 details are not bundled. Some devices and browsers have storage quotas and may remove previously cached files. A full first-install, high-resolution offline copy of every map layer is not included.

Custom saved pins, favorites, collection progress, and routes are stored on your device. Export a JSON backup before changing devices or clearing website data.
