🗂 Team Jura · Data pack rules

Atlas 5.0 accepts additional location sets. They must contain real coordinates with documented permission or a license allowing reuse. GTADB already supplies both games’ landmark data. Game-specific collectibles and vehicle spawns need separate verified data.

Supported fields

{
 "id": "my-unique-dataset",
 "license": "CC BY 4.0",
 "attribution": "Creator name and contributors",
 "sourceUrl": "https://source.example/credits",
 "records": [
   {"id":"location-1","game":"5","scope":"online",
    "category":"collectible","name":"Actual verified location",
    "x":1234,"y":-432,"uncertain":false}
 ]
}

Accepted licenses: CC BY 4.0, CC0, MIT, Public Domain, or Original / authorized. The importer checks format, not whether a third party really gave you permission. Check the source before importing/publishing. The supplied example pack uses the already-available Mount Josiah landmark from GTADB with proper attribution and verified source coordinates. Importing it is for testing the pack mechanism only and will duplicate a landmark already in the base dataset. It does not include vehicle spawns or collectibles.

Game "5" is Los Santos, with scope "story", "online", or "both". Game "6" is Leonida research. Category values include "collectible", "vehicle", "property", "weapon", "activity" and ordinary landmark categories. Vehicle means a verified spawn, not a dealership.

Download example JSON. Packs are installed only in the current browser and kept in local storage. Publish authorized packages with clear attributions when ready.
